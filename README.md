# Morellatos Tattoo Studio

Projeto de desenvolvimento web criado para demonstrar minhas habilidades em HTML, CSS e JavaScript, com foco em uma experiência visual moderna para um estúdio de tatuagem.

## Demonstração

🌐 **Acesse o site:** https://pabloandrad2009-dotcom.github.io/morellatos-tattoo-studio/

## Sobre o projeto

O Morellatos Tattoo Studio é um projeto de portfólio desenvolvido para explorar a criação de um site responsivo, com identidade visual própria e recursos interativos.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivos de desenvolvimento

- Construir uma interface visual atraente.
- Praticar estruturação semântica com HTML.
- Trabalhar estilos e responsividade com CSS.
- Implementar interações com JavaScript.
- Publicar um site estático usando GitHub Pages.
